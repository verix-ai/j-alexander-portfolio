# Jonathan Alexander — Portfolio

Personal design portfolio: brand identity, campaigns, packaging, environmental design, and photography.

Built with [Next.js](https://nextjs.org) and [Tailwind CSS](https://tailwindcss.com).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Production

```bash
npm run build
npm start
```
